# mi-portfolio - José Vicente Herrero López

Sitio web personal y currículum digital desarrollado como proyecto práctico para el ciclo formativo de **FP Grado Superior en Desarrollo de Aplicaciones Web (DAW)**. 
Aquí presento mi trayectoria profesional, mi formación académica en el sector tecnológico y mis datos de contacto.

## Enlace a la web publicada

Visitar el portfolio en funcionamiento a través de GitHub Pages:  
https://github.com/JoseVHL/mi-portfolio/

## Tecnologías utilizadas

* **HTML5:** Estructura semántica del contenido (`header`, `nav`, `main`, `section`, `article`, `footer`).
* **CSS3:** Estilos personalizados y diseño *responsive* adaptado a distintos dispositivos.
* **JavaScript:** Interactividad en la sección de Preguntas Frecuentes.
* **Git y GitHub Pages:** Control de versiones y alojamiento web.

## Contenido del portfolio

* **Perfil Profesional:** Resumen de mi experiencia en gestión y atención al cliente, junto con mi reorientación profesional hacia el desarrollo web.
* **Formación:** Estudios actuales en 2º de DAW y titulación previa en Sistemas Microinformáticos y Redes (SMR).
* **Preguntas Frecuentes (FAQ):** Respuestas interactivas sobre mis conocimientos y disponibilidad laboral.
